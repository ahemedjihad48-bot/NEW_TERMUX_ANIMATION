📥 INSTALLATION

Extract the project and enter the directory:

cd Termux-os-master

Then run:

bash os.sh

Termux-OS will handle the required setup automatically.


---

🔧 TROUBLESHOOTING

If package installation has a problem, update Termux first:

pkg update
pkg upgrade

Then start Termux-OS again:

bash os.sh

If permission is required:

chmod +x os.sh

Then:

./os.sh
